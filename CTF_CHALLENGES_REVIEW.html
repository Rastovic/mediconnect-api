Welcome to MediConnect CTF — landing page copy (draft)

MediConnect looks like a normal hospital patient portal — appointments, lab results, prescriptions, messages between patients and doctors. It's also riddled with security holes, on purpose. Your job is to find them and break in.

Start here

  1. Log in as the patient below and just use the app for a few minutes — book an appointment, open your labs, message a doctor. Get a feel for how it's meant to work before you start bending it.
  2. Open the Challenges page. Each one tells you what you're trying to pull off and roughly where to poke. Pick a category, read the goal, go digging.
  3. When an exploit lands, you'll turn up a flag — a string like flag{...}. Drop it into the challenge to score it.
  4. Watch your progress fill in. The nastier the bug, the more it's worth.

That's the only login you're given. There are doctors, a pharmacist, and an admin in here too — getting into their accounts is half the challenge. If you're logged in as someone you shouldn't be, you're doing it right.

Ground rules — it's a sandbox built to be attacked; nothing here touches a real system. The easy ones are meant to feel too easy. Hints exist but cost points, so try first. Have fun. Break things.

How flags & duplicates work

Capture — flags are stored only as salted hashes; the plaintext lives at the exploit's endpoint (record, file, internal URL, callback). Perform the attack, submit the string, server verifies.

● Shared flag — where the same pattern repeats across many endpoints (IDOR etc.), one flag is reachable via any path.

● Distinct twist — a duplicate with a genuinely different angle is promoted to its own flag.

● Fixed — boring near-duplicates with no teaching value are remediated on the ctf-platform branch (no dead-ends).
